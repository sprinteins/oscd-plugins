# Plugin Theming

The visual appearance that OpenSCD plugins receive from their host or use when running standalone.

## Language

**Host theme**:
The visual settings an OpenSCD host provides to its plugins.

**Branding**:
The visual identity applied to a plugin, such as the default OpenSCD or TBW branding. It can include colors, typography, and shape.

**Appearance mode**:
The light, dark, or system appearance used by a plugin, independently of its branding.
