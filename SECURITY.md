# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately to [steward@linuxfoundation.org](mailto:steward@linuxfoundation.org). Do not disclose vulnerabilities in public issues. Include affected components and versions, the potential impact, and steps to reproduce when possible.

## CRA stewardship

This project is supported under the Linux Foundation CRA stewardship framework, as described at [Linux Foundation Security](https://www.linuxfoundation.org/security).

Security reports will be coordinated with our CRA steward. If you learn of an actively exploited vulnerability or a severe incident, such as a compromise of the release process, notify [steward@linuxfoundation.org](mailto:steward@linuxfoundation.org) immediately while you work to fix the issue.
